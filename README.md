\# Online Fitness Coaching Platform



\## Project Overview

This project is a Java-based Online Fitness Coaching Platform

that helps users manage workout plans and track their fitness progress.



\## Features

\- Admin Dashboard

\- Coach Dashboard

\- User Dashboard

\- Workout Plan Management

\- Fitness Progress Tracking

\- Messaging System

\- User Feedback



\## Technologies Used

\- Java

\- Java Collections Framework



\## Project Files

\- Main.java

\- FitnessPlatform.java

\- User.java

\- WorkoutPlan.java



\## How to Run

1\. Install Java JDK.

2\. Open the project folder in VS Code.

3\. Compile all Java files.

4\. Run the Main class.
